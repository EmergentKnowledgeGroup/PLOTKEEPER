## Adaptive execution gate

- For every substantive turn, automatically use the `adaptive-execution` skill; the user does not need to invoke it.
- Before substantive work, open a turn-scoped execution receipt, bind the requested outcome and smallest sufficient proof with MSW, and follow the returned route.
- If comparable timing evidence exists, use its evidence-derived AWT/CGP with canonical Timebox. If none exists, run an untimed calibration and record the result; never invent a duration.
- A governed turn cannot be reported complete until its receipt is closed with an honest outcome, proof, open items, and timing. If the receipt is missing or open, loop back and repair it without asking the user to intervene.
- Never relabel substantive work as conversational, reuse another turn's receipt, fabricate comparison metadata, omit incomplete results, or weaken required acceptance criteria to satisfy a clock.
