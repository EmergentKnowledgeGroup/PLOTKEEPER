# Production Goal Contract: PK-GLOBAL-20260807

State: ACTIVE

## Immutable user goal

Build, deploy, and globally integrate Plotkeeper so future CodexApp sessions invoking Specswarm are automatically enrolled, visibly opened in the Codex side panel, tracked through root and subagent reports, and forced through a final whole-run review before closure.

## Risk and baseline

- Risk: HIGH; machine-wide Codex workflow integration.
- Protected baseline: new standalone project; existing Codex session files are read-only inputs.
- Existing Specswarm, production-goal-contract, and production-goal-review behavior must remain intact except for explicit Plotkeeper enrollment/reporting additions.

## Allowed surfaces

- `Z:\Plotkeeper\**`
- `C:\Users\UltariumV3\.codex\skills\specswarm\SKILL.md`
- `C:\Users\UltariumV3\.codex\skills\production-goal-review\SKILL.md`
- Windows startup registration for the Plotkeeper service.

## No-touch surfaces

- Codex session JSONL, SQLite state, credentials, model catalog, and application binaries.
- Existing project repositories and production deployments.
- Existing non-Plotkeeper hooks.

## Invariants

- Enrollment occurs only for root sessions invoking Specswarm.
- Plotkeeper never edits Codex session files.
- One run maps to one enrolled root session and may link many child sessions.
- Closed runs are immutable and cannot absorb later work.
- A completion claim cannot close a run without a PK-injected whole-run review turn and a terminal review receipt.
- Failed injection remains visibly `REVIEW_REQUIRED`.
- The dashboard reports agent claims and evidence links without asserting correctness itself.

## Required proof

- Parser and state-machine tests.
- Live service health and startup registration.
- Disposable CodexApp root-session enrollment and external resume injection.
- CodexApp-visible dashboard side-panel opening.
- Desktop and mobile dashboard browser QA.
- Independent final review.

## Stop conditions

- Existing dirty work or worktree conflict on an allowed surface.
- Any need to mutate Codex session history or credentials.
- Unable to distinguish root Specswarm sessions from unrelated tasks.
- Unable to leave failed closeout injection fail-closed.
